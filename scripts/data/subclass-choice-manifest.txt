# Subclass choice manifest — D&D 5e 2014 rules
#
# Every subclass feature that makes the player pick something when they gain
# it. scripts/check-subclass-completeness.mjs checks that the app offers a
# picker for each, with the right count and options. Names only, no rules text.
#
# Format:
#   [Class]
#   Subclass Name
#     <level> <Feature Name> = <kind> x<count>[: Option; Option; ...]
#
# kind: options (a fixed named list, given after the colon), skills, cantrips,
# spells, languages, tools, weapons, armor (the app may build these lists
# itself, so only the picker's presence is checked).
# A trailing " ?" means "less certain, check against the book".
#
# Arcane Trickster spells are not listed: the level-up wizard has its own
# spell step for them. Eldritch Knight is listed because it has none.
#
# Choices made each time a feature is used (Starry Form, Form of the Beast,
# Eldritch Cannon) are not listed: they are not build choices.
