# Subclass feature manifest — D&D 5e 2014 rules
#
# The reference list that scripts/check-subclass-completeness.mjs compares
# src/data/en/2014_subclasses.json against. Names, levels and sources only:
# no rules text, so it is safe to keep in a public repo.
#
# Format:
#   [Class]
#   Subclass Name (SOURCE)        one line per subclass
#     <level> <Feature Name>      one line per feature, indented
#     - <Option Name>             a pickable option or scaling row the data may
#                                 list as its own feature; allowed, not required
#
# A trailing " ?" on a subclass or feature line means "less certain, check
# against the book". Remove the "?" once someone has checked it.
#
# Not listed on purpose: features that only grant a spell list ("Domain
# Spells", "Oath Spells", "Circle Spells", "<X> Magic", "Expanded Spell List")
# and scaling-only rows such as "Additional Arcane Shot Option". The checker
# ignores those in the data too.
#
# Source codes: PHB, DMG, SCAG, XGE, TCE, EGW, VRGR, FTD, BGG, DSotDQ.
